PyVirtualSystem Ultimate · Manual

Compiler

Lexer produces tokens, parser validates instructions, labels resolve to bytecode addresses, and optional constant folding optimizes safe arithmetic expressions.

CPU / ALU

Step executes one virtual instruction. Arithmetic and bitwise operations update ACC, R1, R2 and Z/C/N/V flags. PUSH/POP demonstrate a bounded stack.

Operating system

Each process owns its program counter, variables, registers and stack. Round Robin, FCFS, SJF and Priority scheduling are educational scheduling policies.

Debugger

Add a bytecode-PC breakpoint, inspect the selected process, watch variables, step backwards, and save/load source code.

Virtual memory

The paging lab independently models a four-frame page cache with FIFO or LRU replacement. It is a teaching model, not an actual memory manager.

This is a browser-based educational simulation, not a real CPU or operating-system kernel.
